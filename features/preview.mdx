## Overview

The live preview panel renders your Markdown content in real-time as you type, providing immediate visual feedback on formatting, structure, and final appearance. It uses react-markdown for secure, standards-compliant rendering with prose styling optimized for technical documentation.

<Info>
The preview panel is the middle column in Verbalize's three-column interface, positioned between the editor and results panels.
</Info>

## Preview Rendering

The preview uses ReactMarkdown for client-side rendering:

```typescript
// From app/page.tsx:377-386
<div
  ref={previewRef}
  onScroll={handleScroll}
  className="flex-1 p-10 overflow-y-auto custom-scrollbar"
>
  <article className="prose prose-slate dark:prose-invert max-w-none prose-headings:font-black prose-headings:tracking-tight prose-a:text-blue-600 prose-img:rounded-xl">
    {/* ReactMarkdown is secure by default as it does not render HTML unless explicitly configured with rehype-raw */}
    <ReactMarkdown>{text || '*Rich preview will appear here...*'}</ReactMarkdown>
  </article>
</div>
```

**Key features:**
- Instant rendering without page reloads
- Security by default - HTML tags are escaped
- Dark mode support with theme-aware styling
- Responsive typography with prose classes

### ReactMarkdown Import

```typescript
// From app/page.tsx:4
import ReactMarkdown from 'react-markdown';
```

ReactMarkdown is a React component that renders Markdown using the CommonMark specification without the security risks of `dangerouslySetInnerHTML`.

## Synchronized Scrolling

The preview panel maintains scroll synchronization with the editor:

```typescript
// From app/page.tsx:130-138
const handleScroll = (e: React.UIEvent<HTMLElement>) => {
  const source = e.currentTarget;
  const target = source === editorRef.current ? previewRef.current : editorRef.current;

  if (target) {
    const percentage = source.scrollTop / (source.scrollHeight - source.clientHeight);
    target.scrollTop = percentage * (target.scrollHeight - target.clientHeight);
  }
};
```

**How it works:**
1. Detect scroll event on either editor or preview
2. Calculate scroll position as percentage of total height
3. Apply same percentage to the other panel
4. Works bidirectionally - scroll either panel

<Note>
Proportional scrolling ensures alignment even when rendered content height differs from source text height due to headings, images, or formatted elements.
</Note>

## Security

ReactMarkdown is secure by default:

```typescript
// From app/page.tsx:383 comment
{/* ReactMarkdown is secure by default as it does not render HTML unless explicitly configured with rehype-raw */}
```

**Security features:**
- HTML tags are escaped and displayed as text
- No script execution from user input
- No XSS vulnerabilities from Markdown content
- Safe for untrusted user input

<Note>
If you need to render HTML in Markdown, you must explicitly add the `rehype-raw` plugin. Verbalize intentionally omits this for security.
</Note>

## Performance Considerations

The preview re-renders on every keystroke:

```typescript
// From app/page.tsx:362
onChange={(e) => setText(e.target.value)}
```

ReactMarkdown is optimized for this use case:
- Fast parsing with unified/remark ecosystem
- Efficient React reconciliation for incremental updates
- No syntax highlighting overhead (plain code blocks)
- Handles documents up to 100,000 characters smoothly

<Info>
For very large documents (>100,000 characters), you may notice slight input lag. Consider splitting large documents into smaller sections for optimal performance.
</Info>

## Typography Best Practices

The prose styling optimizes for technical documentation:

### Reading Width

```css
max-w-none  /* Full width, no artificial constraint */
```

Unlike blog posts, technical docs benefit from wider text to accommodate code examples and tables.

### Heading Hierarchy

```css
prose-headings:font-black
prose-headings:tracking-tight
```

Extra-bold headings with tight tracking provide strong visual hierarchy for scanning documentation structure.

### Link Styling

```css
prose-a:text-blue-600
```

Blue links follow web conventions for instant recognizability. Hover states add underlines for additional feedback.

### Image Styling

```css
prose-img:rounded-xl
```

Rounded corners (12px radius) soften technical screenshots and diagrams.

## Limitations

<CardGroup cols={2}>
  <Card title="No HTML Rendering" icon="code">
    HTML tags are escaped for security. Use pure Markdown syntax only.
  </Card>
  <Card title="No Syntax Highlighting" icon="paintbrush">
    Code blocks render with monospace font but without language-specific highlighting.
  </Card>
  <Card title="No MDX Components" icon="puzzle-piece">

  </Card>

    LaTeX/KaTeX math notation is not supported without additional plugins.
  </Card>
