## Overview

The Markdown editor is the primary workspace in Verbalize where you write and edit your technical documentation. It features a clean, distraction-free interface with monospace font rendering and synchronized scrolling with the preview panel.

<Info>
The editor supports documents up to 1MB in size and automatically normalizes line endings to ensure consistent linting results.
</Info>

## Document Upload

Load Markdown and MDX files directly into the editor from your local filesystem:

```typescript
// From app/page.tsx:100-111
const handleDocUpload = (e: React.ChangeEvent<HTMLInputElement>) => {
  const file = e.target.files?.[0];
  if (!file) return;

  const reader = new FileReader();
  reader.onload = (event) => {
    const content = (event.target?.result as string).replace(/\r\n/g, '\n');
    setText(content);
  };
  reader.readAsText(file);
  if (docInputRef.current) docInputRef.current.value = '';
};
```

<Note>
Uploaded files have their line endings normalized to `\n` to ensure Vale produces accurate line and column numbers in linting results.
</Note>

**Supported formats:**
- `.md` - Markdown files
- `.mdx` - MDX (Markdown with JSX)

**Access from sidebar:**


## Synchronized Scrolling

The editor and preview panels maintain synchronized scroll positions for seamless content navigation:

```typescript
// From app/page.tsx:130-138
const handleScroll = (e: React.UIEvent<HTMLElement>) => {
  const source = e.currentTarget;
  const target = source === editorRef.current ? previewRef.current : editorRef.current;

  if (target) {
    const percentage = source.scrollTop / (source.scrollHeight - source.clientHeight);
    target.scrollTop = percentage * (target.scrollHeight - target.clientHeight);
  }
};
```

**How it works:**
1. Detect scroll events on either the editor or preview panel
2. Calculate the scroll position as a percentage of total scrollable height
3. Apply the same percentage to the target panel
4. Bidirectional - works when scrolling either panel

<Info>
This proportional scrolling approach ensures the editor and preview remain aligned even when the rendered content has different heights than the source text.
</Info>

## Alert Navigation

Click on any linting alert in the results panel to jump directly to the problematic text in the editor:

```typescript
// From app/page.tsx:140-196
const handleAlertClick = (alert: ValeAlert, e: React.MouseEvent) => {
  if ((e.target as HTMLElement).closest('a')) return;

  e.preventDefault();
  e.stopPropagation();

  if (!editorRef.current) return;

  const textarea = editorRef.current;
  const currentValue = textarea.value;
  const lines = currentValue.split('\n');
  let offset = 0;

  // Calculate offset based on current textarea value
  for (let i = 0; i < Math.min(alert.Line - 1, lines.length); i++) {
    offset += lines[i].length + 1; // +1 for \n
  }

  const start = offset + alert.Span[0] - 1;
  const end = offset + alert.Span[1];

  // ... scroll calculation and text selection ...
  textarea.focus();
  textarea.setSelectionRange(start, end);
};
```

**The navigation system:**
1. Converts line numbers to character offsets
2. Uses a shadow textarea to calculate accurate scroll positions
3. Centers the selected text in the viewport
4. Highlights the problematic text with a selection
5. Handles text wrapping for accurate positioning

<Note>
The shadow textarea technique accounts for line wrapping and ensures the selected text is properly centered regardless of font size or editor width.
</Note>

## Vale Alert Interface

Linting results use the `ValeAlert` interface for type-safe alert handling:

```typescript
// From app/page.tsx:8-21
interface ValeAlert {
  Action: {
    Name: string;
    Params: string[] | null;
  };
  Span: [number, number];  // Character span within the line
  Check: string;           // Rule name (e.g., "Google.Passive")
  Description: string;     // Detailed explanation
  Link: string;            // Documentation URL
  Message: string;         // User-facing error message
  Severity: string;        // "error", "warning", or "suggestion"
  Match: string;           // The matched text
  Line: number;            // Line number (1-indexed)
}
```
