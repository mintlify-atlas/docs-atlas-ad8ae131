## What is Verbalize?

Verbalize is a powerful web application designed to help technical writers create high-quality documentation by providing real-time linting against industry-standard style guides. Built with Next.js and powered by Vale CLI, Verbalize offers an intuitive three-column interface featuring an editor, live preview, and instant feedback.

## How It Works

<Steps>
  <Step title="Write Documentation">
    Use the built-in Markdown editor to write your technical documentation with full syntax support
  </Step>
  <Step title="Select Style Guide">
    Choose your preferred style guide (Google, Microsoft, or Red Hat) or upload custom Vale rules
  </Step>
  <Step title="Run Linting">
    Click the lint button to analyze your documentation against the selected style guide
  </Step>
  <Step title="Review Results">
    View detailed alerts with severity levels, line numbers, and style guide references in the results panel
  </Step>
</Steps>

## Why Verbalize?

<Note>
Verbalize combines the power of Vale CLI with a modern, user-friendly interface to make documentation quality assurance accessible to all technical writers.
</Note>

- **Zero Configuration**: Start linting immediately with pre-configured style guides
- **Professional Standards**: Leverage industry-leading style guides from Google, Microsoft, and Red Hat
- **Extensible**: Add your own custom rules to match your organization's standards
- **Developer-Friendly**: Built with TypeScript, Next.js, and React for easy customization
- **Open Source**: MIT licensed and available on GitHub
