## Overview

The Verbalize API implements comprehensive error handling with descriptive error messages and appropriate HTTP status codes. All errors return JSON responses with an `error` field containing a human-readable message.

## Error Response Format

```typescript
interface ErrorResponse {
  error: string;
}
```

**HTTP Status Codes**:
- `400` - Client-side errors (validation failures, invalid input)
- `500` - Server-side errors (Vale execution failures, internal errors)

## Validation Errors (400)

Validation errors occur when the request doesn't meet input requirements. These errors are caught at `app/api/lint/route.ts:21-43`.

### Missing or Invalid Text

**Trigger**: Text field is missing, null, or not a string

<CodeGroup>
```json Response
{
  "error": "No text provided or invalid format"
}
```


## Server Errors (500)

Server errors occur during Vale execution or internal processing. These are caught at `app/api/lint/route.ts:124-149`.

### Vale Execution Failed

**Trigger**: Vale binary execution fails without parseable output

<CodeGroup>
```json Response
{
  "error": "Vale execution failed"
}
```
</CodeGroup>

**Possible Causes**:
- Vale binary not found or not executable
- Vale binary corrupted
- Configuration file errors
- System resource exhaustion
- Timeout (Netlify Functions: 10 seconds)

**Source Code**:
```typescript
try {
  const { stdout } = await execFileAsync(
    valePath,
    [`--config=${iniFile}`, '--output=JSON', tmpFile]
  );
  const results = JSON.parse(stdout);
  return NextResponse.json(results[tmpFile] || []);
} catch (error: unknown) {
  const execError = error as { stdout?: string; message?: string };
  
  if (execError.stdout) {
    // Try to parse output even on non-zero exit
    try {
      const results = JSON.parse(execError.stdout);
      return NextResponse.json(results[tmpFile] || []);
    } catch {
      return NextResponse.json(
        { error: 'Failed to parse Vale output' },
        { status: 500 }
      );
    }
  }
  
  console.error('Vale execution failed:', execError.message || execError);
  return NextResponse.json(
    { error: 'Vale execution failed' },
    { status: 500 }
  );
}
```
**Location**: `app/api/lint/route.ts:119-137`

<Info>
**Note**: Vale returns non-zero exit codes when it finds linting alerts. This is expected behavior and the API handles it by checking for stdout content.
</Info>

**Troubleshooting Steps**:

1. **Verify Vale Installation**
   ```bash
   node scripts/install-vale.js
   vale --version
   ```

2. **Check Vale Permissions**
   ```bash
   chmod +x vale
   ```

3. **Test Vale Manually**
   ```bash
   echo "test" > test.md
   vale --output=JSON test.md
   ```

4. **Check Netlify Function Logs**
   - Navigate to Netlify dashboard → Functions → View logs
   - Look for Vale execution errors

## Timeout Errors

### Netlify Function Timeout

**Limit**: 10 seconds (default)

**Symptoms**:
- Request hangs
- No response received
- Netlify shows timeout in logs

**Mitigation Strategies**:

1. **Reduce Document Size**
   ```javascript
   // Split large documents into chunks
   const MAX_CHUNK_SIZE = 50000; // 50KB per request
   const chunks = splitIntoChunks(text, MAX_CHUNK_SIZE);
   
   const results = await Promise.all(
     chunks.map(chunk => 
       fetch('/api/lint', {
         method: 'POST',
         body: JSON.stringify({ text: chunk, style })
       })
     )
   );
   ```

2. **Limit Style Guides**
   - Use one style guide instead of multiple
   - Remove unused custom rules

3. **Increase Timeout (netlify.toml)**
   ```toml
   [functions]
     timeout = 30
   ```

4. **Optimize Vale Configuration**
   - Use `MinAlertLevel = warning` instead of `suggestion`
   - Disable unnecessary rules

## Client-Side Error Handling

### Recommended Pattern

```typescript
interface LintResponse {
  data?: ValeAlert[];
  error?: string;
}

async function lintDocument(
  text: string,
  style: string,
  customRules?: CustomRule[]
): Promise<LintResponse> {
  try {
    const response = await fetch('/api/lint', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ text, style, customRules })
    });
    
    const data = await response.json();
    
    if (!response.ok) {
      return { error: data.error || 'Unknown error occurred' };
    }
    
    return { data };
    
  } catch (error) {
    // Network errors, JSON parse errors, etc.
    return { 
      error: error instanceof Error 
        ? error.message 
        : 'Failed to connect to linting service'
    };
  }
}
```

### Error Display Example

```typescript
const handleLint = async () => {
  setLoading(true);
  setError(null);
  
  const { data, error } = await lintDocument(text, style, customRules);
  
  if (error) {
    // Display user-friendly error message
    switch (true) {
      case error.includes('maximum allowed length'):
        setError('Document is too large. Please reduce to under 1MB.');
        break;
      case error.includes('Invalid style guide'):
        setError('Please select a valid style guide.');
        break;
      case error.includes('Vale execution failed'):
        setError('Linting service unavailable. Please try again.');
        break;
      default:
        setError(error);
    }
  } else {
    setResults(data || []);
  }
  
  setLoading(false);
};
```

### Retry Example

```typescript
async function lintWithRetry(
  text: string,
  style: string,
  maxRetries: number = 3
): Promise<ValeAlert[]> {
  let lastError: Error;
  
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      const response = await fetch('/api/lint', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ text, style })
      });
      
      if (response.ok) {
        return await response.json();
      }
      
      // Don't retry 400 errors (client mistakes)
      if (response.status === 400) {
        const error = await response.json();
        throw new Error(error.error);
      }
      
      // Wait before retrying (exponential backoff)
      await new Promise(resolve => 
        setTimeout(resolve, Math.pow(2, attempt) * 1000)
      );
      
    } catch (error) {
      lastError = error as Error;
      if (attempt === maxRetries - 1) throw lastError;
    }
  }
  
  throw lastError!;
}
```

## Error Reference Table

| Status | Error Message | Cause | Solution |
|--------|--------------|-------|----------|
| 400 | No text provided or invalid format | Missing or non-string text field | Provide valid string in `text` field |
| 400 | Text exceeds maximum allowed length... | Text > 1MB | Reduce document size or split into chunks |
| 400 | Invalid style guide selected | Style not in allowed list | Use 'Google', 'Microsoft', or 'RedHat' |
| 400 | Too many custom rules. Maximum is 10 | More than 10 custom rules | Remove some custom rules |
| 400 | Rule "X" exceeds maximum... | Rule content > 10KB | Simplify rule or split into multiple rules |
| 500 | Vale execution failed | Vale binary issues | Reinstall Vale, check permissions |
| 500 | Failed to parse Vale output | Invalid JSON from Vale | Reinstall Vale, check rule syntax |
| 500 | Internal server error | Unexpected server error | Check logs, verify request format |
