## What is Verbalize?

Verbalize is a web-based SaaS application designed specifically for technical writers who want to ensure their documentation adheres to industry-standard style guides. Built with Next.js 16, TypeScript, and React, Verbalize provides real-time linting feedback powered by the Vale CLI engine.

## Key Capabilities

### Style Guide Validation

Verbalize supports three industry-standard style guides out of the box:

```typescript
const ALLOWED_STYLES = ['Google', 'Microsoft', 'RedHat'];
```

Each style guide includes comprehensive rules for:
- Grammar and punctuation
- Terminology and word choice
- Formatting conventions
- Tone and voice consistency

### Real-time Architecture

Verbalize uses a request-response cycle that processes your documentation through Vale CLI:

```
User Interface (Browser)
         ↓
    POST /api/lint
    { text: string }
         ↓
Next.js API Route (/app/api/lint/route.ts)
         ↓
    1. Receive text input
    2. Create temporary file
    3. Execute Vale CLI
         ↓
    Vale Engine
         ↓
    4. Load .vale.ini
    5. Apply style rules
    6. Generate diagnostics
         ↓
    JSON Response
    { diagnostics: [...] }
         ↓
User Interface (Display lint suggestions)
```

<Note>
  Vale outputs JSON-formatted diagnostics with severity levels (error, warning, suggestion) that are transformed into a frontend-friendly structure.
</Note>

## Design Philosophy

### User Experience Principles

1. **Minimal Cognitive Load** - The interface prioritizes the writing workspace with non-intrusive feedback
2. **Real-time Feedback** - Linting results appear immediately without page reloads
3. **Accessibility First** - All interactive elements include proper ARIA labels and keyboard navigation
4. **Single-Page Workshop** - Editor, preview, and diagnostics are visible simultaneously

### Interface Layout

Verbalize uses a three-column layout for maximum productivity:

```typescript
// From app/page.tsx:338-448
<div className="flex-1 grid grid-cols-1 lg:grid-cols-3 overflow-hidden">
  {/* Column 1: Editor - Write your documentation */}
  <section className="flex flex-col border-r">
    <textarea
      value={text}
      onChange={(e) => setText(e.target.value)}
      className="flex-1 p-8 font-mono text-sm"
      placeholder="Start typing your documentation (Markdown supported)..."
    />
  </section>

  {/* Column 2: Preview - See rendered Markdown */}
  <section className="flex flex-col border-r">
    <ReactMarkdown>{text}</ReactMarkdown>
  </section>

  {/* Column 3: Results - View linting alerts */}
  <section className="flex flex-col">
    {results.map((alert) => (
      <div onClick={() => handleAlertClick(alert)}>
        {alert.Message}
      </div>
    ))}
  </section>
</div>
```

## Data Types

### Vale Alert Structure

Each linting alert from Vale follows this TypeScript interface:

```typescript
interface ValeAlert {
  Action: {
    Name: string;
    Params: string[] | null;
  };
  Span: [number, number];
  Check: string;
  Description: string;
  Link: string;
  Message: string;
  Severity: string;
  Match: string;
  Line: number;
}
```
